# Improvements — open, prioritized (P0–P3), cited

* [Public /api/copilotkit accepts anonymous POSTs that spend LLM and Tavily credit](copilotkit-endpoint-unauthenticated.md) - The only server route runs the agent and Tavily search with server keys for any caller - no auth, rate limit or origin check; only maxSteps bounds one turn
* [Dark-mode tokens and dark: classes ship but nothing ever enables dark mode](dark-mode-inert.md) - globals.css defines a .dark token block and a dark custom variant, and components carry dark: classes, but no code adds the dark class and no theme library is installed
* [lib/user-info.ts is imported by nothing](dead-user-info-module.md) - getUser and getUsers are leftover demo mock code with no importer; they suggest a user model the app does not have
* [Conversion Rate KPI is a hard-coded constant presented as derived data](hardcoded-conversion-rate-kpi.md) - calculateConversionRate divides customers by customers*8.13, so it always shows about 12.3% - and that fabricated figure is shown as a KPI tile and fed to the agent as a metric
* [pnpm lint calls oxlint, which is not a dependency](lint-script-oxlint-missing.md) - The lint script runs oxlint . but oxlint is absent from package.json and the lockfile, so pnpm lint fails on a clean clone
* [next 16.1.7 carries 2 critical and 12 high advisories - bump to 16.3.3](next-16-1-7-critical-cves.md) - rafa audit (osv-api + pnpm audit) flags 25 advisories on the direct dep next@16.1.7, incl. 2 critical unauthenticated RCEs; all fixed by 16.3.3
* [No CI - tests, type-check and build never run on push or PR](no-ci-gate.md) - The repo has no .github workflows or other CI config; pnpm test, check-types and build only run when someone remembers to run them locally
* [postcss 8.4.31 pinned by next has 2 high path-traversal advisories](postcss-sourcemap-cves.md) - next@16.1.7 pins postcss@8.4.31, flagged for arbitrary file read via sourceMappingURL (2 high, 2 moderate); fixed in 8.5.23
* [README preview.gif is a Git LFS pointer, so the README image is broken](readme-preview-lfs-pointer.md) - preview.gif is a 133-byte LFS pointer text file with no .gitattributes or LFS object in this repo - the README hero image renders broken
* [sharp 0.34.5 (via next) has 2 high advisories in libvips and libheif](sharp-libvips-libheif-cves.md) - Transitive sharp@0.34.5 under next carries GHSA-f88m-g3jw-g9cj and GHSA-rgj7-g3m4-5g8c; fixed in 0.35.4
* [Accessibility test regex-matches exact indentation in app/page.tsx](source-text-tests-brittle.md) - page-accessibility.test.mjs extracts the Suspense fallback with a regex that hard-codes six- and four-space indentation, so a formatter run breaks the test with no behaviour change
* [The test script names each test file - a new test file silently never runs](test-script-explicit-file-list.md) - pnpm test lists four files explicitly; any new *.test.* file is skipped with no error, so coverage can erode unnoticed
* [next.config turbopack.root resolves three levels above the standalone repo](turbopack-root-outside-repo.md) - turbopack.root is path.resolve(__dirname, ../../..) - the old monorepo root - so Turbopack roots itself outside this repo (for a checkout on Desktop that is the user's home dir)
* [undici 5.29.0 under @copilotkit/runtime carries 3 high advisories](undici-transitive-cves.md) - @copilotkit/runtime > @ai-sdk/google-vertex > @ai-sdk/provider-utils@3.0.40 pulls undici@5.29.0 - 13 advisories (3 high); fixes are in undici 7.24-8.10
* [Seven runtime dependencies are declared but imported nowhere](unused-template-dependencies.md) - @tremor/react, react-hook-form, @hookform/resolvers, four @radix-ui packages, date-fns, react-day-picker and class-variance-authority are template leftovers that no file imports
